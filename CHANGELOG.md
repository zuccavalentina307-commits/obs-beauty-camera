# Changelog

## 2.1.0 - 2026-11-01

- Added the **Refined** preset and made it the default for new sources and filters.
- Tuned the clear look for a more neutral, realistic skin tone.
- Added the built-in illustrated manual (`manual.html`) and an in-panel manual button.
- Added a contact/support chapter with the project's support card.
- Reworked packaging so the ZIP can be merged directly into an OBS install directory.
- Unified all version strings to 2.1.0.

## 2.0.0 - 2026-11-01

- Added automatic multi-face tracking (up to 3 faces) with manual ellipse fallback.
- Added the full D3D11 shader feature set: smoothing, whitening, rosy tone, clarity, spot repair, eye/teeth/dark-circle, contouring, side shadow, three makeup styles, five color looks, face/eye/chin shaping, body slimming, background blur, glow, grain, vignette, and split comparison.
- Added nine presets (including Custom), full Chinese/English UI, and camera capture controls.
- Added the OBS filter mode for existing video sources.

## 1.0.0 - 2026-11-01

- Initial release: OBS source/filter skeleton, GPU beauty shader, basic smoothing and whitening controls.
