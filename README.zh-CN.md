# 美颜相机插件 v2.1.0

一个完全本地运行的 OBS 美颜插件：自动面部追踪（最多 3 张脸）、磨皮祛斑、美白红润、眼部/牙齿/黑眼圈、立体修容、三种美妆、五种滤镜色调、瘦脸大眼、美体与背景虚化、画面特效、左右分屏对比。无联网、无账号、无会员、无授权校验。

- 来源名称：**美颜相机**（内置摄像头采集 + 美颜）
- 滤镜名称：**美颜相机滤镜**（可添加到任意摄像头或视频源）
- 模块 ID：`obs-beauty-camera`
- 默认预设：**精致（推荐）**
- 内置说明书：插件属性面板最上方「说明书 → 打开使用说明书」，内含使用说明与「联系与支持」章节

## 安装：拖进 OBS 安装目录即可自动加载

OBS 启动时会自动扫描安装目录下的 `obs-plugins/64bit` 和 `data/obs-plugins`。本插件完全遵循该结构，复制进去就会自动加载，不需要安装程序、不需要改配置。

1. **完全退出 OBS**（包括托盘中的后台进程），否则 DLL 被占用会复制失败。
2. 解压安装包，得到 `obs-plugins` 和 `data` 两个文件夹。
3. 把这两个文件夹**拖进 OBS 安装目录**，与 OBS 自带的同名文件夹合并：
   - 安装版默认：`C:\Program Files\obs-studio`
   - 便携版：`obs64.exe` 所在目录
4. 询问是否合并/替换时选择「是」。
5. 重新启动 OBS。在「来源 → 添加」看到「美颜相机」，或在任意源右键「滤镜 → 添加」看到「美颜相机滤镜」，即加载成功。

> 升级旧版：关闭 OBS 后，用本包中的同名文件覆盖旧文件即可；然后重新启动 OBS。
>
> 如果 OBS 正在运行，DLL 会被占用。必须先退出 OBS 再覆盖，不能只关闭窗口后立即复制。

## 两种使用方式

### 美颜相机来源

「来源 → 添加 → 美颜相机」。属性面板直接选择摄像头、分辨率、帧率、视频格式、色彩空间、色彩范围、缓冲和垂直翻转，同时调节全部美颜参数。摄像头采集由插件内部创建，画面已经带美颜，不需要再手动加滤镜。

### 美颜相机滤镜

右键任意视频源 →「滤镜 → 添加 → 美颜相机滤镜」。适合已有摄像头采集、采集卡、媒体源、视频文件或虚拟摄像头画面。滤镜会跟随源的分辨率自动适配，美颜区域以外的背景像素保持原样。

## 默认效果：精致（推荐）

v2.1.0 新建来源/滤镜时默认使用「精致」预设：轻磨皮、轻美白、保留皮肤纹理，配合适度清晰度、通透感和轻微气色。目标是干净、真实、不假面，适合日常直播、会议、录课。

内置 9 个预设：精致（推荐）、自然、清透、奶油肌、立体、直播、甜美、冷白、港风。选择预设后，被预设接管的滑杆会锁定；切到「自定义」即可逐项微调。

## 技术说明

- 单 Pass HLSL 着色器，Direct3D 11 GPU 渲染：YCbCr 肤色判定 + 椭圆/多脸权重 + 亮度门限 + 双边磨皮 + 多半径斑点修复 + 高光保护美白 + 中间调红润 + 反锐化清晰度 + 局部 UV 变形（瘦脸/大眼/下巴/美体）+ 眼部/牙齿/黑眼圈区域处理 + 妆容着色 + 滤镜色调 + 背景虚化 + 发光/颗粒/暗角 + 分屏对比。
- 自动面部追踪：GPU 画面回读缩放到 160 像素宽，CPU 进行肤色连通区域分析，每 250 毫秒更新，最多 3 张脸；检测到脸时自动替换手动椭圆，检测不到时回退到手动椭圆。全程本地，不上传画面。
- 渲染遵循 OBS 滤镜规范（`obs_source_process_filter_begin/end`），支持任意源尺寸；美颜区域以外背景像素保持不变。
- 摄像头来源内部创建私有 `dshow_input` 子源并挂载私有滤镜，属性面板直接读写子源参数。
- 说明书按钮使用 `obs_module_file` 定位本地 `manual.html`，并调用系统默认浏览器打开；不依赖网络。

- Windows 10 / 11，64 位。

## 从源码构建

源码：`src/plugin.c`；着色器：`src/beauty.effect`（运行时拷贝到 `data/obs-plugins/obs-beauty-camera/beauty.effect`）。

依赖：MinGW-w64 x86_64 GCC、OBS 29.1.3 源码头文件、由 `obs.dll` 生成的导入库 `obs.a`。

```bash
make OBS_INCLUDE=<obs-studio>/libobs OBS_LIBDIR=<lib-dir>
```

等价命令：

```bash
gcc -shared -O2 -s -static-libgcc \
    -o obs-beauty-camera.dll src/plugin.c \
    -I<obs-studio>/libobs -L<lib-dir> \
    -lobs -lshell32 -ladvapi32
```

构建产物 `obs-beauty-camera.dll` 放入 `obs-plugins/64bit/`；着色器、说明书、海报与语言文件放入 `data/obs-plugins/obs-beauty-camera/`。

## 已知限制

- 自动追踪基于肤色连通区域，不是深度学习人脸关键点：肤色接近的背景、极端侧脸、口罩或大面积遮挡可能影响定位；此时可关闭自动追踪，改用手动椭圆。
- 美体瘦身与背景虚化为 2D 屏幕空间近似，复杂背景或多人画面效果有限。
- 美颜为 2D 屏幕空间处理，极端角度或大面积遮挡时肤色判定可能不完美。
- 分屏对比的分割线固定约 1.5 像素宽，高分辨率下较细。
- 仅在 OBS 29.1.3 x64 实机验证；更高版本未逐版测试。
