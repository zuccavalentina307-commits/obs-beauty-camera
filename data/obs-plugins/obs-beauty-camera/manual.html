01安装与自动加载

插件采用 OBS 标准的目录结构。把压缩包里的 obs-plugins 和 data 两个文件夹直接合并进 OBS 安装目录，OBS 下次启动时会自动扫描并加载，不需要执行安装程序，也不需要改任何配置。

  1. 完全退出 OBS。包括右下角托盘里的后台进程，确保 OBS 没有占用插件文件。
  2. 找到 OBS 安装目录。安装版通常是 C:\Program Files\obs-studio；便携版就是 obs64.exe 所在的文件夹。你也可以在 OBS 里打开「文件 → 显示设置文件夹」，再回到上一级确认。
  3. 把 obs-plugins 和 data 拖进 OBS 安装目录。系统询问是否合并时选择「是」，询问是否替换同名文件时选择「替换」。这两个文件夹里只多出本插件自己的文件，不会影响 OBS 自带插件。
  4. 重新启动 OBS。在「来源 → 添加」里能看到「美颜相机」，在任意源右键「滤镜 → 添加」里能看到「美颜相机滤镜」，就说明已自动加载成功。

安装后的文件位置

obs-studio/ ├─ obs-plugins/ │ └─ 64bit/ │ └─ obs-beauty-camera.dll 插件主程序 └─ data/ └─ obs-plugins/ └─ obs-beauty-camera/ ├─ beauty.effect GPU 着色器 ├─ manual.html 这份说明书（属性面板按钮会打开它） └─ locale/ ├─ en-US.ini 英文界面 └─ zh-CN.ini 中文界面

为什么能自动加载？OBS 启动时会自动扫描 obs-plugins/64bit 下的 DLL，并按模块名读取 data/obs-plugins/<模块名> 里的着色器和语言文件。本插件严格遵循这一结构，所以文件放对位置即可生效。

替换旧版前请先退出 OBS。如果 OBS 正在运行，DLL 会被占用，复制会失败或留下旧文件。关闭 OBS 后再覆盖，然后重新启动。

02两种使用方式

方式一：美颜相机（自带摄像头）

「来源 → 添加 → 美颜相机」。在属性里直接选择摄像头、分辨率、帧率、视频格式、色彩空间、色彩范围、缓冲和垂直翻转，同时调节全部美颜参数。

摄像头采集由插件内部创建，画面已经带美颜，不需要再手动加滤镜。适合只用 OBS 做直播或录制的场景。

方式二：美颜相机滤镜

右键任意视频源 →「滤镜 → 添加 → 美颜相机滤镜」。适合已有的摄像头采集、采集卡、媒体源、视频文件或虚拟摄像头画面。

滤镜会跟随源的分辨率自动适配，除美颜区域外，背景像素保持原样。

属性面板在哪里

双击来源打开属性，或点击来源下方的「属性」按钮。最上方是说明书分组，点「打开使用说明书」随时打开这份文件；下面是摄像头、美颜开关与预设、磨皮美肤、眼部与牙齿、面部追踪与脸型、立体与阴影、美妆、滤镜色调、美体与背景、色彩调整、画面特效等分组。

对比模式

在「美颜开关与预设 → 对比模式」中可选择：关闭（正常美颜）、仅显示原图（临时查看未处理画面）、左右分屏对比（左半原图、右半美颜，中间有白色分割线）。调参时用分屏最直观，正式开播前记得切回「关闭」。

03推荐起点：精致

v2.1.0 的默认预设是 精致（推荐）：轻磨皮、轻美白、保留皮肤纹理，加上适度的清晰度和通透感，正面看起来干净、真实、不假面。新建来源或滤镜后不需要调任何滑杆，直接就能用。

为什么要保留纹理

磨皮过重会把毛孔、胡须和五官边缘一起抹平，画面显得糊、像塑料。精致预设把磨皮控制在轻中度，同时用清晰度和轻锐化把眼睛、眉毛、发丝拉回来。

想更明显怎么办

在预设里选择「直播」或「奶油肌」，或者切到「自定义」后单独提高磨皮、美白、红润。每一项都能独立调，不会牵一发动全身。

05调参建议

先光后美颜

先把摄像头曝光、白平衡和现场灯光调好，再用美颜。光线不足时强行提高美白和磨皮，画面会发灰、噪点明显。

磨皮和清晰度成对调

磨皮提高后，清晰度也要略微提高，眼睛和五官才不会糊。皮肤细节保护保持在 55 以上，纹理更真实。

一次只改一个滑杆

配合「左右分屏对比」，每次只改一个参数，确认效果后再改下一个，比一次拉满更容易找到合适值。

脸型类参数要克制

瘦脸、大眼、下巴、美体属于局部变形，超过 10–12 容易出现边缘拉扯。自动追踪正常时再使用。

06常见问题

添加来源里找不到「美颜相机」？

先确认 OBS 是 64 位版本，并检查 obs-plugins/64bit/obs-beauty-camera.dll 是否存在。再查看 OBS 日志（帮助 → 日志文件 → 查看当前日志）里是否有 [beauty-camera] module loaded。如果 DLL 放错层级、被安全软件拦截，或 OBS 没有完全退出就覆盖文件，都会导致加载失败。

摄像头列表是空的？

「美颜相机」来源依赖 OBS 自带的 win-dshow 视频采集插件。如果它被删除或禁用，可以改用「美颜相机滤镜」加在任意摄像头源上，美颜功能完全一样。

自动追踪不准或画面里没有脸？

自动追踪基于肤色连通区域，不是深度学习关键点。肤色接近的背景、极端侧脸、口罩或大面积遮挡可能影响定位。此时关闭「自动面部追踪」，用「面部中心 X / Y」和「面部范围」手动对准脸部即可。

画面变糊、细节没了？

降低「磨皮」，提高「皮肤细节保护」和「清晰度（锐化）」。如果使用了「奶油肌」预设，切回「精致」或「自定义」。

肤色发灰、发蓝或偏色？

把「滤镜风格」切到「关闭」或「清透」，把「滤镜强度」降到 30–45；再用「色温」向暖调微调。也要检查摄像头本身的白平衡。

说明书按钮打不开？

说明书文件位于 data/obs-plugins/obs-beauty-camera/manual.html。如果被删除或移动，按钮会失效；从安装包里把 manual.html 复制回该目录即可。也可以直接用浏览器打开这个文件。

会影响 OBS 自带插件或其他美颜插件吗？

不会。本插件使用独立的模块名 obs-beauty-camera、独立的来源 ID 和滤镜 ID，只新增自己的文件，不修改 OBS 程序和其他插件。

需要联网或登录吗？

不需要。所有处理都在本机显卡上完成，不上传画面、不校验账号、没有会员限制。自动追踪同样只在本地运行。

07卸载与兼容性

卸载

  1. 完全退出 OBS。
  2. 删除 obs-plugins/64bit/obs-beauty-camera.dll。
  3. 删除整个 data/obs-plugins/obs-beauty-camera/ 文件夹。
  4. 重新启动 OBS。

卸载不会影响 OBS 自带插件，也不会删除你的场景和录制文件。
